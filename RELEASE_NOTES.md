# Spesh Base 3.1.0.4

- Bundles the Spesh Cinematic theme for authenticated client theme sync: cinema-black surfaces, rounded cards, gold accents, and a blue focus fallback.
- Administrator-uploaded revisions of the same theme take precedence; existing user profiles and selected themes are preserved.
- Includes the appearance profile fragment and design reference in source for the separate SpeshTV client redesign. No new web frontend or native app is included in this plugin update.

Requires Jellyfin 12.4.0 and a server restart after plugin installation. Existing hosted frontend persistence is retained. Client-side gradient focus, SpeshTV branding, trailers and redesigned screens are delivered by separate client builds.
